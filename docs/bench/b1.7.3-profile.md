# Profile: the rest of the frame (b1.7.3, development.md 3.1)

2026-11-12. Scene `busy_bench` (`tools/testscene/scenes/`): overworld_day's spot with 80 mobs, rain, Fancy, smooth
lighting, Normal distance, the bench orbit; Intel UHD / Mesa 26.1.8, 1280×720; Altrender's terrain (Phase 2).
Bench: 146.2 FPS average.

- **CPU:** a JFR recording of exactly the measured 25 s (`-Daltrender.debug.benchJfr`), Java and native samples every
  2 ms; 4,578 samples on the main thread, attributed to the stage on their stack (native time in the GL driver counts
  for the code that called it).
- **GPU:** timestamp queries around each of the game's stages (`-Daltrender.debug.gpuTimers`, StageProfileMixin), ms
  per frame.

## Main thread

| Share | Where | Notes |
|---|---|---|
| 54.2% | buffer swap | waiting for the GPU: the frame is mostly GPU-bound now |
| 10.9% | weather (rain/snow) | per frame, a biome lookup per column through the biome noise (`SimplexNoise.add` 4.7%) plus immediate-mode draws |
| 8.8% | Altrender terrain update | walks every section in range each frame; + 2.6% urgent-section scan, 2.1% visibility walk |
| 7.3% | the game's `WorldRenderer#cullChunks` | frustum-tests the game's own 2,312 sections, which Altrender no longer draws: dead work |
| 8.2% (in several stages) | `Tesselator#end` | client-array draws of everything immediate-mode (weather, entities, particles, sky parts) |
| 4.9% | entities | `ModelPart#render` 3.5% |
| 2.1% / 0.9% | clouds / sky | |

## GPU (ms per frame, typical second)

| Stage | ms |
|---|---|
| weather | 2.3–3.4 |
| terrain (layer 0 / 1) | 1.2–2.3 / 0.2–0.3 |
| sky, clouds | 0.2, 0.2 |

## Ranking and what fixes what

1. **Weather**: the largest cost on both sides. CPU: cache the biome per column (it never changes) instead of the
   noise per frame; draw the columns from a stream buffer (3.2). GPU: it's blended fill; cheaper only by drawing fewer
   pixels, which would change the picture.
2. **Dead and own overhead** (no plan item; no pixel change): skip the game's `cullChunks` while Altrender draws the
   terrain; make the terrain update, urgent scan and visibility walk incremental.
3. **Immediate-mode stream** (3.2): every `Tesselator#end` uploads client arrays.
4. **Entities** (3.4): ~5%.
5. **Sky and clouds** (3.3): ~3% CPU, 0.4 ms GPU.

## After Phase 3 (2026-11-12)

The same scene and recording, with 3.2–3.8 in. The first run had GPU timers on as well (a little CPU each stage), so
compare shares and the per-frame estimate, not the FPS.

| Main thread | Before | After |
|---|---|---|
| buffer swap (waiting for the GPU) | 54.2% | 73.1% |
| weather | 10.9% | 6.3% |
| Altrender terrain draw (incl. the visibility walk) | 6.3% | 10.3% |
| Altrender terrain update | 8.8% | 1.3% |
| the game's `cullChunks` | 8.0% | 0% |
| entities | 4.9% | 3.5% |
| clouds / sky | 2.1% / 0.9% | 2.1% / 0.9% |
| `Tesselator#end` (in several stages) | 8.2% | 8.9% |
| **work per frame outside the swap** | **≈ 3.1 ms** (146 FPS) | **≈ 1.3 ms** (204 FPS) |

The frame is now mostly GPU-bound on this machine; what's left on the CPU is spread thin (weather's immediate-mode
columns and the game's per-column precipitation height, the terrain multi-draws, entity models).
