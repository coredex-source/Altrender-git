# Parity: Altrender vs the game (b1.7.3)

Altrender's terrain (development.md 2.4) against the vanilla references in `reference/b1.7.3/` (same machine: Intel
UHD, Mesa 26.1.8, GL 4.6 compatibility, 1280×720, `ar_debug` textures; method in `README.md`). Shots a and b of each
run are bit-identical (the scene is deterministic); the columns compare shot a with the reference.

**What differs:** single pixels, scattered, denser with distance: triangle edges and nearest-neighbour texels that land
the other way. The game's fixed-function path multiplies its matrices on the CPU (per section: camera modelview ×
1024-block region offset × section offset × the 1.000001 crack scale) and the driver applies the product; Altrender's
shader composes the same chain in a different order on the GPU, so positions differ in the last bits. The meshes
themselves are identical to the game's (2.2's mesh test) and UVs are stored as the game's floats.

**The nether scene** is a weak test: the camera faces dark, fogged blocks at close range, so nothing lands near a texel
or edge boundary. A better Nether scene belongs to the next scene revision.

**Found on the way (fixed):**
- Fancy graphics draws translucent terrain twice: depth only through `WorldRenderer#render`, then colour through
  `renderLastChunks`; Altrender draws both.
- Translucent sections are drawn nearest first, as the game does (Fast graphics draws them in one pass with depth
  writes, so the order decides what shows).
- The game's own section compiler is what loads (or generates) chunks near the camera in singleplayer; Altrender's
  scheduler now asks for a section's chunks the same way (the snow scene, far from spawn, had holes).
- 16-bit UVs rounded the game's 0.01-pixel tile inset across texel boundaries: UVs are floats (20-byte vertex).

## 2026-11-12: Phase 3 (sky buffers, entity culling, immediate-mode changes)

**The nine scenes:** the same numbers as above, scene for scene (and 0 tracker mismatches), with the stream on; with
it off (the default, see `docs/decisions.md`) the game's own client-array draws are back.

**Entities (3.5):** `cave_entities` (49 mobs inside the rock around the cave scene): 51.04 dB against the game, like
`cave`; Altrender skips 34–44 of them (the visibility walk never reaches their sections); culling on vs off:
bit-identical.

**Steps applied as the game's options screen does them (3.8),** each shot compared with the game doing the same:

| to the Nether (portal trip) | 57.42 | |

Resize, minimise, fullscreen and GUI scale aren't scriptable in the harness (it pins its own framebuffer): the owner's
sign-off session.

## 2026-11-12: Phase 4 (gl45 fast paths)

All ten scenes on gl45 and on gl33: the numbers above, 0 tracker mismatches, and **gl45 bit-identical to gl33** in
every scene. The draw paths inside gl45 (CPU-written indirect commands, the default; GPU-written commands; no indirect
draws) are bit-identical to each other and to gl33 in overworld_day, overworld_fast, snow, entities and cave. The
immediate-mode stream (opt-in) is bit-identical on both tiers.
